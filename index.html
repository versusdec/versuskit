VersusKit

Набір класів для найчастіших стилів і готові компоненти. Даєш елементу класи, і окремий CSS для нього не потрібен. Приклади нижче живі, код під ними згенерований з їхньої ж розмітки.

Як це працює

Новинка

Картка без жодного рядка CSS

Відступи, фон, тінь, розмір і колір тексту задані класами.

Структура

scss/
  _variables.scss   ← кольори, відступи, шрифт, брейкпоінти
  _mixins.scss      ← tablet / mobile / hover і кілька хелперів
  base/             ← reset, заголовки, контейнер, анімації
  components/       ← кнопки, форми, модалка, dropdown…
  utilities/
    _classes.scss     ← кольори, текст, рамки, позиціонування…
    _responsive.scss  ← відступи, flex, grid, display + tab- / mob-
  main.scss         ← єдиний файл, що компілюється
css/main.css
js/main.js          ← модалки, dropdown, тогли + твій код
js/vendor/jquery.min.js

Компіляція

Компілюється тільки scss/main.scss → css/main.css. Код сумісний і з Dart Sass (sass), і з node-sass.

sass --watch scss/main.scss:css/main.css --silence-deprecation=import
node-sass --watch scss/main.scss -o css

Якщо все ж потрібен свій стиль

Створи файл, наприклад scss/blocks/_header.scss, і підключи в main.scss у блоці «Стилі проєкту». Змінні й міксини в ньому доступні одразу.

.header {
  height: 80px;

  @include mobile {
    height: 60px;
  }
}

Відступи адаптивна

Відступи задаються класами прямо в HTML, CSS для цього писати не треба. Нижче по кроках: як читається назва класу, що він робить, конструктор і готові рецепти.

1. Як читається назва класу

mob-коли · необов'язково ptщо · властивість - mdскільки · розмір

mob-pt-md означає: на мобільному (≤ 768px) дати відступ зверху всередині (padding-top) розміром md (30px). Без префікса клас діє на всіх екранах: pt-md.

2. Що: властивість

p… padding: відступ всередині елемента (фон його заливає) m… margin: відступ зовні, від сусідів gap: проміжки між дітьми flex/grid

Друга літера означає сторону: top, right, bottom, left; x — ліво+право, y — верх+низ. Повне слово (padding, margin) — усі чотири сторони.

8. Пастки

ПроблемаПричина і рішення
gap-* не працюєgap діє лише у flex або grid. Додай батькові flex чи grid.
mt-* на <a> чи <span> не працюєВертикальні відступи не зсувають inline-елементи. Додай block або inline-block.
mx-auto не центруєБлоку потрібна ширина, менша за батьківську: width-50, width-fit або max-width.
Два margin «злилися»Вертикальні margin сусідніх блоків схлопуються: mb-lg + mt-md дає 40, а не 70. Використовуй gap або відступ лише з одного боку, наприклад завжди mb-*.
Клас не спрацьовує на компонентіУтиліти перебивають компоненти з одним класом (.btn, .card), але не вкладені селектори на кшталт .card .title і не style="".
У власному SCSS ті самі значення доступні як $gap-md або var(--gap-md).

Бургер JS

Три лінії, що перетворюються на хрестик, коли кнопка має .active або aria-expanded="true". Разом з data-toggle перемикає меню. Колір береться з currentColor.

API main.js

Усе працює через делегування подій ($(document).on), тому елементи, додані в DOM пізніше (AJAX, шаблони), підхоплюються автоматично. Свій код пиши в кінці $(function () { … }) у main.js.

Reset і заголовки

Що робить reset

  • box-sizing: border-box для всіх елементів.
  • Прибирає відступи в body, h1–h6, p, blockquote, figure.
  • ul/ol з будь-яким class втрачають маркери й відступи. Списки без класу (з CMS) лишаються звичайними.
  • Картинки й відео: display: block; max-width: 100%.
  • Поля форм успадковують шрифт; button без фону, рамки й відступів.
  • Рамку фокусу видно лише при навігації з клавіатури.
  • Атрибут hidden завжди ховає елемент.
  • При системному налаштуванні «менше анімацій» анімації вимикаються.

Заголовки

h1–h6 (і класи .h1–.h6) самі зменшуються на планшеті й мобільному. Розміри задані в base/_typography.scss.
